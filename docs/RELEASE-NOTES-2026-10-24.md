# 案情板 CaseBoard 1.0.0-beta.1 · 2026-10-24 更新简介

> 一句话：这一版把「钉子」钉进了画布——集中钉子与钉集、钉子之间的红线、可直接输入的数字层级，导出也终于不再丢线。

产物：`CaseBoard-release-2026-10-24.exe`（19,170,816 B，单文件绿色版，运行需系统自带 WebView2）

---

## 新增：集中钉子与钉集

- **集中钉子**：画布上的一颗圆点钉。挂一张黄色便利贴（可显隐、可写字），只有一条关系线连接点，与圆点同心、位于便利贴上边中点。
- **新建时询问**：从左栏点「集中钉子」会先弹窗问「要不要便利贴 + 便签文字」，默认不带。
- **钉集**：把图片拖到钉子上松手就钉住，整集一起走；拖钉子或拖集内任意一张图，等价于拖整集。
- **集内可控**：图片只能绕钉子旋转与移动；右栏有「相对钉子的 X / Y」「自身旋转」三条滑块 + 数字框，每个自由度一行；钉子右栏可增删成员。
- **层级独立**：钉集内部层级单独排序，对外永远浮在卡片与普通图片之上。

## 新增：钉子之间的红线

- 长按一颗集中钉子 → 菜单「创建红线」→ 再点另一颗钉子，两者之间连一条**红色实线**。
- 红线**不是关系线**：不计入关系数、不进时间线/地图/导出清单，也不出现在关系面板的类型里。
- 粗细可调：右栏「案件概览 → 集中钉子之间的红线 → 线宽」一个滑块（1–12px），全局生效。
- 红线压在卡片之上、钉子之下，不会被卡片挡住。

## 新增：层级（上下层）可直接输入

- 所有节点右栏都有「层级（zIndex）」：置顶 / 上移一层 / 下移一层 / 置底，外加一个可直接输入数字的输入框（0–9999）。
- 层级写进代码视图（`z:`），改文本也能改层级。

## 新增：把卡片收进组框

- 长按卡片 →「多选卡片」→ 继续点其它卡片 → 右栏「加入组框…」。
- 也可以在组框成员清单、「分组总览」里直接挑节点加入，卡片会按顺序排进框内、框自动撑大。

## 修复

- **导出 `.caseboard` 再打开，红线消失**：导入侧的文档归一化是「白名单重建」，把红线与线宽设置一起丢了。已修，并补了一条「真的导出、真的再打开」的自动断言。
- **红线看不见**：钉子原本只有 source 连接点，以钉子为终点的线算不出终点；外加两颗钉子可能建在同一坐标、线长 0。三处都已修。
- **右键菜单**：新增「删除此节点（连带其关系线，可撤销）」；删钉子会同时解绑其钉集成员、清掉相关红线，一步撤销。
- **钉集成员拖动时相对位置会变**：拖动预览与推导坐标优先级错了，已修。
- **导出 SVG/PNG** 原先不画集中钉子和红线，现在都画（钉子半径做了 9–15px 夹取，老文档 168×132 的钉子不会被画成巨块）。

## 界面与文案

### 能装的设备

| 条件 | 说明 |
|---|---|
| 系统版本 | **HarmonyOS 6**（工程 `compatibleSdkVersion` = `26.0.0`，5.x 装不上） |

| 签名匹配 | 本包含正式证书 `caseboard_oh_271024.cer` + Release profile，设备需信任该证书链 |

### 安装

```bash
# USB 连上设备后（hdc 在 DevEco Studio 的 SDK toolchains 目录下）
hdc list targets
hdc install -r CaseBoard-harmony-26-2026-10-24.hap
```

也可以直接把 `hdc install -r` 换成 DevEco Studio 打开工程后点运行；或把 hap 拖进 DevEco 的 Device Manager。

升级安装会保留案卷数据；卸载会清空应用沙箱（素材、缩略图、本地案卷都在里面），需要先导出 `.caseboard`。

### 为什么 GitHub 上给 `.hap` 而不是 `.app`

- `.hap` 是模块安装包，能用 `hdc install` 直接装到设备上，适合开发者与小范围试用。
- `.app` 是**上架物料**（`hvigorw assembleApp` 的产物），只能上传到 AppGallery Connect 审核，用户拿到后无法自己安装。
- 想让普通用户「点一下就装」，只有一条路：把 `.app` 传 AGC，走应用市场的公开测试/邀请测试。

## 已知限制

- 这是**绿色版 exe**，不是安装包；未做代码签名，Windows 首次运行可能提示「未知发布者」。
- 需要系统已安装 WebView2 运行时（Windows 10/11 一般自带）。
- 鸿蒙版只提供 `.hap`（开发者模式侧载），不是应用市场版本；上架形态需另行打 `.app` 提交审核。
- 代码视图中「老文档」首次打开会自动补默认值（例如层级 100），这是预期行为，不算改动。
